A decentralized freelance platform with 2% fees and instant crypto payments. Freelancers lose 15-40% of earnings to fees, slow payments, and locked reputation. BaseLance = A freelance platform + Web3 benefits (2% fees, instant payments, portable reputation). Low fees enable micropayments, fast finality, African-friendly.

link to live project: https://baselancee.vercel.app/

Getting started
bashNode.js >= 18
Wallet (MetaMask, Coinbase Wallet, etc.)
Base testnet ETH for gas
Installation
bash# Clone the repository
git clone https://github.com/JohnOluB/baselance.git

# Install dependencies
cd Baselancee
npm install

# Run development server
npm run dev

link to live project: https://baselancee.vercel.app/
