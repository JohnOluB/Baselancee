# **App Name**: BaseLance

## Core Features:

- Freelancer Profile Creation: Enable freelancers to create detailed profiles showcasing their skills, portfolio, and set rates. Wallet connection and reputation on the blockchain is captured.
- Job Marketplace: Provide a platform for clients to post jobs and freelancers to browse and apply. Use an AI-powered tool to provide matching functionality based on skill set and prior work.
- Instant Crypto Payments: Secure funds in smart contract escrow and release payments instantly upon job approval in USDC, with low transaction fees.
- Fee Comparison Tool: Incorporate an interactive tool where users can input their earnings and see a comparison of fees paid on BaseLance versus Upwork or Fiverr.
- On-Chain Reputation: Allow freelancers to build and own their reputation onchain, enabling them to prove their track record anywhere.
- Transparent Dispute Resolution: Implement a transparent dispute resolution process managed by smart contracts.
- Earnings Prediction: Leverage AI to predict a freelancer's potential earnings based on their skills, experience, and demand on the platform.

## Style Guidelines:

- Primary color: Base Blue (#0052FF) for main CTAs and links, conveying trust and innovation.
- Background color: Light blue (#F3F4F6), subtly desaturated, providing a clean, modern backdrop.
- Accent color: Teal (#00D4AA), analogous to Base Blue but distinct, for secondary actions and highlights.
- Font: 'Inter' (sans-serif) for headings and body text, providing a modern and readable experience.
- Use a consistent set of modern icons, with Base Blue (#0052FF) for primary icons and Teal (#00D4AA) for secondary icons.
- Maintain a clean, modern layout with a focus on clear hierarchy and user-friendly navigation.
- Implement subtle animations and transitions to enhance the user experience and provide visual feedback.
